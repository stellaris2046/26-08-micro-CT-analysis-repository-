# Reporting accidental exposure

Do not paste credentials, sample records or private images into a public issue.

If GitHub offers **Security → Report a vulnerability** for this repository, use that private channel. Otherwise contact the maintainer through a verified private channel before sharing details. Do not assume a public issue is confidential.

For maintainers: revoke any exposed credentials first. Remove sensitive content from every affected branch/tag and its history; inspect releases, attachments and workflow artifacts separately. Contact GitHub Support about residual cached commits or references when eligible, and coordinate cleanup of existing clones. A deletion commit or `.gitignore` change alone does not remove historical content.

See [GitHub's sensitive-data removal procedure](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository).
