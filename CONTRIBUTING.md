# Contributing

Submit focused changes with their purpose and validation. Use synthetic coordinates and artificial arrays for reproducible tests. Label them synthetic and avoid deriving them from a real animal or tracing an experimental image.

Do not upload scans, image headers, specimen identifiers, group assignments, annotations, screenshots, measured results, private task records, workstation paths or credentials in commits, issues, pull requests or attachments. If a real dataset is needed for validation, use an independently governed repository with explicit sharing rights; agree on that scope before sharing it.

Scientific method changes should state the affected endpoint, acquisition assumptions, coordinate conventions, review requirements and validation evidence. Preserve the distinction between a proposed parameter, a reviewed measurement and a validated cross-study method.

For calculator changes, run `python -m unittest discover -s tests -v`. Contributions must be original or have compatible licensing with required attribution retained. By submitting a contribution, you agree to make your contribution available under this repository's MIT License and confirm that you have the rights to do so.
